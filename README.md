# Return Policy Decision Lab · UNIQLO case

An interactive decision-support page from an ISEM2005 Management Information Systems group project. It compares three online-return policies for a UNIQLO case scenario (Mainland China, affected online returns):

- **Current Policy**: the customer pays postage and arranges mailing
- **A1 Paid Return Postage**: the company pays postage
- **A2 Store Acceptance**: stores accept online returns

For each handling scenario (Base / Downside / Upside), the page sizes the minimum number of A2 stores against monthly staff capacity. It then compares total resource costs, and lets you adjust every assumption and run sensitivity checks.

- **Open it:** see the GitHub Pages link in the repo's About section.
- **Run locally:** open `index.html` in any browser (it works offline with no dependencies).

*Student coursework. All figures are illustrative assumptions in HKD, not company data. Not affiliated with or endorsed by UNIQLO.*
